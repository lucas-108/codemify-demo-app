# Vercel Deployment Troubleshooting Guide

## Quick Reference: Path Resolution

### The Golden Rule

**All paths in `vercel.json` are relative to the repository root, not the build source.**

```json
{
  "builds": [
    {
      "src": "frontend/package.json", // ← Tells Vercel WHERE to build
      "config": {
        "distDir": "frontend/build" // ← FROM ROOT, where output is
      }
    }
  ]
}
```

## Common Path Issues

### ❌ Wrong (causes DEPLOYMENT_NOT_FOUND)

```json
{
  "src": "frontend/package.json",
  "config": { "distDir": "build" } // Vercel looks for frontend/build from frontend/ = frontend/frontend/build ❌
}
```

### ✅ Correct

```json
{
  "src": "frontend/package.json",
  "config": { "distDir": "frontend/build" } // From root: frontend/build ✅
}
```

## Debugging Checklist

When deployment fails:

1. **Check Vercel build logs**

   - Look for "Output directory not found"
   - Note the path Vercel is looking for

2. **Verify local build**

   ```bash
   cd frontend
   npm run build
   ls -la build/  # Should show index.html, static/, etc.
   ```

3. **Match paths in vercel.json**

   - `distDir` should match your routes' `dest` paths
   - Both should be from repository root

4. **Check .vercelignore**
   - Ensure you're not ignoring the build output
   - Common issue: `build/` in .gitignore AND .vercelignore

## Error Patterns

### DEPLOYMENT_NOT_FOUND

**Cause**: Build output not found at expected path  
**Fix**: Adjust `distDir` to match actual output location from root

### BUILD_FAILED

**Cause**: Build command failed or missing dependencies  
**Fix**: Check `buildCommand` or ensure `npm run build` exists

### ROUTE_NOT_FOUND (404 on deployed site)

**Cause**: Routes point to non-existent files  
**Fix**: Ensure `routes[].dest` matches actual file paths

## Monorepo Best Practices

1. **Use explicit paths**

   ```json
   "distDir": "apps/web/build"  // ✅ Clear
   vs
   "distDir": "build"            // ❌ Ambiguous
   ```

2. **Keep package.json close to source**

   ```
   frontend/
   ├── package.json
   ├── src/
   └── public/
   ```

3. **Document your structure**
   Add comments in vercel.json (they're allowed in Vercel's parser)

## Testing Before Deploy

```bash
# 1. Clean build locally
rm -rf frontend/build
cd frontend && npm run build

# 2. Verify output structure
ls frontend/build/index.html  # Should exist

# 3. Check paths match vercel.json
# distDir: "frontend/build" → frontend/build/index.html ✅

# 4. Dry-run Vercel build
vercel build  # Tests build config without deploying
```

## Quick Fixes

### If you see DEPLOYMENT_NOT_FOUND:

1. Check the path Vercel reports
2. Compare to your actual `ls -la` output
3. Update `distDir` in vercel.json
4. Commit and push

### If local works but Vercel fails:

1. Check for environment-specific paths
2. Verify all dependencies in package.json
3. Check Node version compatibility
4. Review build logs for filesystem errors
